# Sistem Informasi Hotel 2-in-1. Dashboard + Sistem Pemesanan Kamar
Aplikasi ini berisi menu dashboard, sehingga admin/petugas bisa masuk untuk mengatur tamu, pembayaran, dan kamar hotel. Ada juga halaman landing page untuk sebagai tempat pemesanan kamar hotel.
<br>
## 📖 Cara Penggunaan
1. Pastikan XAMPP dan Git terinstal dan berjalan dengan baik pada komputer Windows kalian.
2. Jalankan web server dan MySQL pada XAMPP.
3. Buka terminal/PowerShell lalu ubah direktori saat ini ke direktori htdocs XAMPP kalian. `cd jalur\ke\xampp\htdocs`
4. Salin perintah git clone berikut: `git clone https://github.com/OuwnKuu/sistem-informasi-hotel-windows.git`. Atau bisa juga download file .zip proyek ini lalu extract ke folder htdocs kalian.
5. Setelah proses cloning/extract selesai. Cari file database yang memiliki ekstensi .sql di dalam root proyek. Setelah ditemukan, buka browser dan ketik `localhost/phpmyadmin`
6. Di dalam phpMyAdmin, tekan tombol yang bertuliskan "Import" Lalu tekan tombol untuk memilih file. Cari file SQL yang ada di proyek tadi, dan cari tombol "Go" di bawah.
7. Setelah import selesai, buka tab baru dan ketik `localhost/SistemInformasiHotel`
8. Selamat, website akan berjalan dengan sempurna.
